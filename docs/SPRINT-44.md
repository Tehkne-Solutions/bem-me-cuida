# Sprint 44 — Validação dos planos de correção

## Objetivo

Validar planos de correção integrados contra o estado atual das decisões e do escopo permitido, sem preparar PR real nem executar alterações.

## Classificações

- current-and-compatible
- stale-decision-validation
- duplicate-plan
- conflicting-plan
- scope-divergence
- source-plan-missing
- invalid-plan-reference

## Controles

Todos os resultados permanecem somente leitura, com execução, autorização de correção, preparação de PR, ativação e mutação bloqueadas.

## Fora de escopo

- modificar fontes de verdade;
- gerar patches;
- criar migrations 022–029;
- abrir PR de correção funcional;
- publicar ou ativar o produto.
