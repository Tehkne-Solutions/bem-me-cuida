# ADR 057 — Autorização protegida para início de sessão humana

## Status

Aceito.

## Decisão

A autorização de início da sessão será um registro administrativo determinístico, condicionado a um pacote vigente e compatível.

## Consequências

- a sessão não começa automaticamente;
- o registro não concede poderes operacionais;
- todas as ações funcionais continuam bloqueadas;
- uma etapa humana posterior continua obrigatória.
